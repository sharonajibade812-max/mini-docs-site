# mini-docs-site

A miniature documentation website built with [Quarto](https://quarto.org/) and deployed with GitHub Pages. It contains three short articles for beginners setting up a docs-as-code workflow, covering VS Code and GitHub, rendering Markdown with Quarto, and publishing a site with GitHub Pages.

**Live site:** https://sharonajibade812-max.github.io/mini-docs-site/

## How It Works

Content is written in Markdown (`.qmd` files) and converted to HTML by Quarto, using the settings in `_quarto.yml`. The generated site goes to the `docs` folder, which is where GitHub Pages publishes from.

## Files

- `_quarto.yml` — site title, navigation, theme, and output settings
- `index.qmd` — directory page
- `vscode-github.qmd`, `quarto-render.qmd`, `github-pages.qmd` — the three articles
- `images/` — screenshots used in the articles
- `docs/` — the rendered site, generated by Quarto

## Rebuilding

```bash
quarto render
```

Then commit and push. GitHub Pages redeploys automatically.
